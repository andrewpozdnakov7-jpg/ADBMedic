# Приёмка TASK-001 — чек-лист пользователя и менеджера

## Перед сдачей

- Начальный handoff ZIP и реальные Android-логи **не копировать в GitHub и не вносить в тестовые фикстуры**. Проверенные исходники публикуются по новому разрешению владельца.
- Не подключать телефон при работе над TASK-001; синтетические данные обязательны.
- Архив исходников проверяется privacy-audit. Имя папки проекта нейтральное, в ZIP нет предыдущего бренда, истории коммитов, автора, реального кейса или старых URL.
- Запустить `.\smoke-test.ps1`, отдельно `privacy-audit.ps1`, проверку безопасной упаковки.
- Убедиться, что офлайн-пакет сырой диагностики и онлайн-ИИ заблокированы с объяснением RU/EN.
- Проверить отсутствие исходящего сетевого трафика при тестах / запуске локального bootstrap.
- Проверить пробелы и кириллицу на вымышленных путях, Windows PowerShell 5.1 и PS7 при наличии.
- Запретить вывод личного пути/серийника в сообщения об ошибках и отчёты.

## Требования к реализации Codex

- Все фикстуры и пути только синтетические.
- Все изменения документированы без значения каких-либо персональных строк.
- `IMPLEMENTATION-001.md`: файлы, цель, тесты и фактические результаты, открытые риски, механизм блокировки.
- Push/PR разрешены только после успешных проверок, в выбранный репозиторий. Не включать Actions, не публиковать релизы и не применять force push.
- Установить локальные Git hooks, проверить Worktree, Staged и всю исходящую History, включая метаданные. Настроить только локальные имя/публичную почту.

## Проверка владельцем

На этапе TASK-001 запускаются только синтетические тесты, **без телефонов и реальных dump-файлов**. Само приложение с подключённым Android тестируется позже после приёмки privacy-gate. При провале тестов отправлять только обобщённую ошибку без пользовательских путей.
