# ADBMedic

[English](../../README.md) · **Русский** · [Español](README.es.md) · [Português](README.pt.md) · [Français](README.fr.md) · [简体中文](README.zh-CN.md)

Собирает диагностику Android и открывает локальный отчёт. Работает в Windows без прав администратора.

## Запуск

1. Подключите телефон по USB и включите на нём отладку по USB.
2. Откройте обычный **Windows PowerShell**.
3. Вставьте команду:

```powershell
irm https://raw.githubusercontent.com/andrewpozdnakov7-jpg/ADBMedic/main/run.ps1 | iex
```

Подтвердите установку и сбор данных. Если ADB ещё нет, программа предложит его скачать. На телефоне разрешите отладку для этого компьютера. После сбора выберите **1 — открыть отчёт** или **2 — посмотреть папку с отчётом**. Ничего не открывается автоматически; Enter завершает работу.

Когда программа подтвердит готовность диагностического ZIP, прикрепите **ADBMedic-report.zip** в чат нейросети, которой доверяете, и попросите выполнить инструкцию внутри. ИИ выступает специалистом по Android: объясняет причины расхода по реальным приложениям, указывает значения, типы и периоды событий, даёт пошаговый план и способ проверить результат. При нехватке данных назначает точечные read-only ADB-команды с объяснениями. [Полный контракт ИИ](../../AI-ANALYST.md). Пункт 2 открывает папку с ZIP. Если чат не читает ZIP, приложите REPORT.md, facts.json, MANUAL-ANALYSIS-PROMPT.md и нужные файлы из evidence.

Интерфейс диагностики пока поддерживает русский и английский: язык выбирается автоматически по языку интерфейса Windows. Для остальных языков используется английский. Выбирать режим или указывать параметры не нужно.

## Если проект уже скачан

В архив включены **SUMMARY.md** и структурированные сведения о батарее в **facts.json.analysis**: периоды статистики, привязки UID к пакетам, оценки расхода, типы счётчиков и ссылки на строки. Пропуски, неизвестные форматы и противоречия отмечаются явно. Полные файлы остаются в evidence для проверки; первичная обработка не объявляет диагноз.

Скопируйте показанный после сбора стартовый промпт в чат вместе с ZIP. Он также находится в отчёте и **START-PROMPT.txt** рядом с ZIP и внутри него. Язык ответа ИИ по умолчанию — язык интерфейса Windows; явная просьба о другом языке в чате имеет приоритет.

Откройте PowerShell в папке проекта и запустите:

```powershell
.\bootstrap.ps1
```

## Ваши данные

Скрипт читает диагностику и сохраняет её на вашем компьютере в `%LOCALAPPDATA%\ADBMedic`. Настройки телефона он не меняет. Диагностические данные в облако не отправляются.

ZIP содержит приватную диагностику: жалобу, модель/Android, время сбора, реальные имена процессов и пакетов, UID/PID и подробные дампы. Просмотрите его и решите, передавать ли выбранному ИИ. Не публикуйте архив в GitHub. Известные шаблоны секретов и приватных ключей блокируют упаковку; это не гарантия обнаружения всех секретов. Автоматической отправки и выполнения советов ИИ нет. [Формат экспорта и ограничения](../SAFE-HANDOFF.md).

Проверено в Windows PowerShell 5.1. Полный запуск с реальным телефоном ещё требует проверки.
