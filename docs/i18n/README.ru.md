# ADBMedic

[English](../../README.md) · **Русский** · [Español](README.es.md) · [Português](README.pt.md) · [Français](README.fr.md) · [简体中文](README.zh-CN.md)

Собирает диагностику Android и открывает локальный отчёт. Работает в Windows без прав администратора.

## Запуск

1. Подключите телефон по USB и включите на нём отладку по USB.
2. Откройте обычный **Windows PowerShell**.
3. Вставьте команду:

```powershell
irm https://raw.githubusercontent.com/andrewpozdnakov7-jpg/ADBMedic/main/run.ps1 | iex
```

Подтвердите установку и сбор данных. Если ADB ещё нет, программа предложит его скачать. На телефоне разрешите отладку для этого компьютера. После сбора выберите **1 — открыть отчёт** или **2 — посмотреть папку с отчётом**. Ничего не открывается автоматически; Enter завершает работу.

Когда программа подтвердит готовность безопасного ZIP, прикрепите **ADBMedic-report.zip** в чат вашей нейросети (ChatGPT, Claude или другой) и попросите выполнить инструкцию внутри. В архиве есть измерения и запрос на понятные выводы, подробные действия и обратную связь. Пункт 2 открывает папку с ZIP. Если чат не читает ZIP, распакуйте его и прикрепите REPORT.md, facts.json и MANUAL-ANALYSIS-PROMPT.md.

Интерфейс диагностики пока поддерживает русский и английский: язык выбирается автоматически по языку интерфейса Windows. Для остальных языков используется английский. Выбирать режим или указывать параметры не нужно.

## Если проект уже скачан

Откройте PowerShell в папке проекта и запустите:

```powershell
.\bootstrap.ps1
```

## Ваши данные

Скрипт читает диагностику и сохраняет её на вашем компьютере в `%LOCALAPPDATA%\ADBMedic`. Настройки телефона он не меняет. Диагностические данные в облако не отправляются.

Локальный отчёт приватный. Передавайте только подготовленный ZIP: в нём проверенные числовые измерения и условные метки процессов этой сессии, без идентификаторов и сырых логов. Если проверка не пройдена, архив для передачи не создаётся. Автоматического диагноза и отправки в ИИ нет — анализ выполняет выбранный вами чат. [Формат экспорта и ограничения](../SAFE-HANDOFF.md).

Проверено в Windows PowerShell 5.1. Полный запуск с реальным телефоном ещё требует проверки.
