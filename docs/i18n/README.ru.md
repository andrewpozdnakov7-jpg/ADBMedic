# ADBMedic

[English](../../README.md) · **Русский** · [Español](README.es.md) · [Português](README.pt.md) · [Français](README.fr.md) · [简体中文](README.zh-CN.md)

Телефон быстро разряжается или греется? ADBMedic соберёт отчёт для нейросети, которой вы доверяете. Она поможет разобраться и предложит дальнейшие действия.

Нужны **Android-телефон, компьютер с Windows и USB-кабель с передачей данных**. Устанавливать приложение на телефон не нужно.

## 1. Подготовьте телефон

1. Откройте **Настройки → О телефоне → Номер сборки**. Иногда он находится в разделе **Сведения о ПО**. Нажмите **7 раз** и введите PIN-код телефона, если потребуется.
2. Найдите в настройках **Для разработчиков** и включите **Отладку по USB**. Названия меню могут отличаться — воспользуйтесь поиском в настройках.
3. Разблокируйте телефон и подключите его USB-кабелем к своему компьютеру.

## 2. Запустите на компьютере

Откройте «Пуск», введите **Windows PowerShell** и запустите обычным способом. Права администратора не нужны.

Скопируйте команду, вставьте в PowerShell и нажмите **Enter**:

```powershell
irm https://raw.githubusercontent.com/andrewpozdnakov7-jpg/ADBMedic/main/run.ps1 | iex
```

- На вопросы об установке и сборе данных отвечайте **y**, затем Enter. Если программа предложит скачать нужный инструмент, согласитесь.
- Посмотрите на телефон: если появится **«Разрешить отладку по USB?»**, нажмите **«Разрешить»** для своего компьютера.
- Опишите проблему, например: «За ночь сильно садится батарея». Дождитесь окончания сбора.

## 3. Передайте результат нейросети

1. Выберите **2** в PowerShell — откроется папка с отчётом. Пункт **1** позволяет посмотреть отчёт самостоятельно.
2. Прикрепите **ADBMedic-report.zip** в ChatGPT, Claude или другой чат, которому доверяете.
3. Вставьте стартовый промпт из окна PowerShell. Такой же текст есть в **START-PROMPT.txt** рядом с ZIP.

Нейросеть должна объяснить, что видно по данным, предложить действия или назначить конкретную дополнительную проверку. По умолчанию ответ будет на языке Windows; можно попросить другой.

**Телефон не найден?** Разблокируйте его, проверьте разрешение отладки, попробуйте другой кабель с передачей данных или USB-порт. Если ZIP не создан, сохраните текст ошибки; не упаковывайте всю папку вручную.

В отчёте есть личные сведения о телефоне и приложениях. Скрипт ничего не отправляет автоматически. Передавайте ZIP только выбранной нейросети, не публикуйте его в GitHub. После работы отладку по USB можно выключить. Интерфейс скрипта пока русский или английский.

Не закрывайте это окно. Если ИИ попросит дополнительные измерения, выберите здесь **3**: укажите скачанный JSON или вставьте JSON и завершите отдельной строкой **END**. Просмотрите и подтвердите проверки, затем передайте **новый ZIP в тот же чат ИИ**. Если окно уже закрыто, запустите ту же команду и выберите **«Продолжить расследование»** — случай сохранён. [Подробнее](../../agent/investigation-rules.md#running-a-follow-up-request-on-windows).

Когда есть достоверные измерения, ИИ должен показать полезный график со временем, единицами, источниками и пропусками. Если данных нет — объяснить это.
