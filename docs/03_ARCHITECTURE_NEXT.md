# План дальнейших этапов (только проектирование)

**TASK-002: Диагностические данные как типизированные факты.** Источник raw -> parser -> набор строго разрешённых полей -> scrubber/validator -> проверка выходного файла -> ZIP. По умолчанию export only derived telemetry (CPU %, timestamp relative to session, generic process category, power state, thermal classes). Не помещать в безопасный архив оригинальные dumpsys/logcat/bugreport/backtraces по умолчанию. Пакет для облака — отдельный, гораздо меньший, чем локальный архив raw. Неизвестный формат -> reject, не «анонимизировать вслепую».

**TASK-003: Windows/ADB надёжность.** Обработка пустого/unauthorized/offline списка устройств, выбор из нескольких устройств без печати уникальных серийников; обработка скачивания Platform-Tools с проверкой контрольной суммы и отдельного подтверждения.

**TASK-004: Наблюдаемость/диагностика.** Разделение живых срезов и исторических counters, пакетная выборка TIDs при повышенной CPU, локальные безопасные root диагностики только с подтверждением, before/after, журнал гипотез.

**TASK-005: UI / гибридный режим.** Локальный HTML-отчёт, RU/EN UI, отчёт в языке Windows, ограниченные prompts; вообще не передавать полные логи без явного consent и data preview.

Не выполнять эти этапы в TASK-001.
