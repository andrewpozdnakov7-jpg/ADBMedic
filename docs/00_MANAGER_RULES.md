# ADBMedic — действующий регламент

Текущие правила и границы разработки находятся в [AGENTS.md](../AGENTS.md).

Владелец разрешил все шесть пунктов TASK-002: буквальное сохранение технических доказательств, потоковую работу с большими данными, паспорт случая, универсальную инструкцию INVESTIGATE.md, дополнительный Skill и локальный цикл дополнительных проверок по валидируемому JSON.

Локальные ZIP не обезличиваются. UID/PID/TID, пакеты, процессы, сборка и технические сведения сохраняются. Исходники и GitHub отдельно защищены от реальных диагностических данных и секретов. Сбор переписки и содержимого сообщений не предусмотрен. Никакой автоматической отправки, произвольного исполнения команд ИИ, root или изменения телефона.

Проверки разработки только синтетические, без телефона и реального ADB. После успешных проверок — ветка и PR, docs/IMPLEMENTATION-002A.md, затем остановка для приёмки без слияния. Релизы, MCP и подключение ИИ автоматически не входят в объём.
