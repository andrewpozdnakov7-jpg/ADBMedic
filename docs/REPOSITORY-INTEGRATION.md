# Адаптация к GitHub-репозиторию

Дата: 2026-10-26.

Исторический отчёт о первоначальной адаптации. Последующее разрешение на публикацию, полный privacy gate и актуальные результаты описаны в `IMPLEMENTATION-001.md`; прежние формулировки о запрете push ниже относятся к состоянию на момент адаптации.

## Реализовано

- Локальный `origin` указывает на выбранный владельцем репозиторий ADBMedic. Коммиты, fetch, push, публикация и настройка CI не выполнялись.
- Добавлен `Install-ADBMedic.ps1` и команда установки/запуска в README. Установщик запрашивает согласие, получает текущий commit ветки `main`, скачивает 11 явно перечисленных файлов с привязкой к этому commit и проверяет синтаксис PowerShell перед установкой.
- Каждая версия устанавливается в отдельную папку. Повторная установка сравнивает файлы; изменённая локальная копия не перезаписывается. Неполные, пустые и синтаксически некорректные загрузки не активируются. Установщик не читает диагностику.
- `bootstrap.ps1` передаёт `-NoBrowser` вместе с остальными параметрами. По умолчанию новый установщик запускает локальный режим.
- PowerShell-файлы приведены к UTF-8 с одним BOM. В стартовом наборе у четырёх скриптов было два BOM; лишний символ вызывал ранее отмеченные ошибки разбора. Начальная копия и исходный ZIP не менялись.
- Из RU/EN подсказок и предварительного отчёта удалены предложения отправлять сырой ZIP или запускать заблокированный облачный анализ. Блокировки экспорта и анализа сохранены.
- В инструкции проекта внесена обязательная проверка на деанон перед каждой публикацией. Разрешённая публичная почта и необходимые адреса выбранного репозитория описаны как узкие исключения. Атрибуция LICENSE не менялась.

## Проверка

- Windows PowerShell 5.1: offline installer tests — PASS, 33 проверки. Все сетевые вызовы заменены синтетическими заглушками; реальное приложение и ADB не запускались.
- Проверены отказ от установки без сетевых обращений, выполнение установщика как загруженного scriptblock, привязка всех файлов к одному commit, явный запуск и установка без запуска, передача языка/флагов, повторная установка, сохранение локальных правок, неверный commit, ошибки загрузки, невалидный/пустой исходник, удаление временной копии, работа с кириллицей и пробелами в пути.
- Smoke-тесты: PASS. Проверены разбор PowerShell, синтетический список устройств, локали, HTML escaping, блокировка ZIP и сообщения об отключённом экспорте в предварительном отчёте RU/EN.
- PowerShell 7 и работа с реальным Android не проверялись.
- Текущие 28 исходных файлов повторно проверены локальным поиском признаков персональных данных/секретов с узким исключением публичной почты; совпадений не обнаружено. В 12 PowerShell-файлах ошибок статического разбора нет. Это проверка текущей рабочей копии; перед будущим push отдельно проверить точный набор коммитов и его метаданные.

## До публикации

При чтении GitHub API в новом репозитории находились только README и LICENSE. Установщик ещё не опубликован, поэтому команда из README станет доступна после отдельно разрешённой загрузки файлов. Установка с настоящего GitHub end-to-end не проверялась.

Перед разрешённой публикацией повторить проверку на деанон именно отправляемых файлов и метаданных согласно `PUBLICATION-PRIVACY.md`. Публикация не является частью этой адаптации. Шаблон атрибуции LICENSE по-прежнему требует решения владельца; авторство не выводилось из почты или имени аккаунта.

Это адаптация установки к репозиторию, а не завершение всего TASK-001 или реализация sanitizer из TASK-002. Проверка текста не доказывает анонимность произвольных Android-дампов.
