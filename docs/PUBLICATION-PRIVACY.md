# Обязательная проверка перед публикацией

Перед каждой публикацией в Git/GitHub необходимо повторно проверить именно отправляемый набор: содержимое файлов, имена и пути, метаданные, историю коммитов и артефакты. Новые правки после проверки требуют повторной проверки. При неразрешённых находках публикация блокируется.

Запрещены личные имена и имена пользователей, локальные пути профилей, приватные контакты, ключи, токены, идентификаторы устройств, реальные диагностические материалы и любая другая персональная информация. В отчёты не включать найденные значения.

Узкие исключения, прямо разрешённые владельцем:

- `andrewpozdnakov7@gmail.com` — публичная почта, не считается деаноном.
- `Andrew` — явно разрешённое владельцем имя автора коммитов; существующая атрибуция лицензии репозитория сохраняется.
- Адрес выбранного репозитория ADBMedic и необходимые производные API/raw-адреса — ссылки проекта. Имя аккаунта из этих адресов не переносить в посторонние поля, пути или тесты.

Владелец разрешил ветки, коммиты, push и Pull Requests после успешного аудита TASK-001. Существующие ветки не переписывать. Релизы и включение CI не разрешены. Разрешение не распространяется на передачу диагностики и не заменяет повторную проверку после новых правок.

Перед коммитом установить hooks: `./scripts/Install-GitHooks.ps1`. Они проверяют рабочую копию, фактический Git index, автора/сообщение коммита и всю историю каждого исходящего ref. В новом checkout настройка hooks локальная и должна повторяться. Прямой upload через интерфейс GitHub этими hooks не защищён; его не использовать вместо проверенного процесса.

Команды проверок: `./privacy-audit.ps1`, `./privacy-audit.ps1 -Mode Staged`, `./privacy-audit.ps1 -Mode History -Revision HEAD`. Для ZIP исходников использовать только `./scripts/Build-SafeSourceArchive.ps1`; диагностику он не упаковывает.

Новые исходники требуют отдельного внесения в `source-manifest.json` и ручного ревью. В рабочей копии приватные каталоги не читаются; при их принудительном добавлении в index проверка блокирует коммит. Неразрешённые имена файлов в выводе редактируются.

Автоматический поиск шаблонов не заменяет ручной просмотр и не гарантирует анонимность Android-дампов. Сырые диагностические данные не публикуются.
